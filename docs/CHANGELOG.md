# 更新记录

## 0.4.0 · 2026-10-25

- WebUI 成员页补齐虚拟地址、状态、角色、通道、延迟、版本展示，筛选和 CSV 导出同步扩展。
- 创建网络增加确认密码与官方长度校验；管理按钮按当前网络管理员权限启用。
- GUI / WebUI 增加可配置绑定地址、端口和令牌的只读 API，提供健康检查、状态和 schema 接口。
- 增加 Windows 防火墙 IP 阻断、解除阻断和规则列表；IP / MAC 工具改为程序内置脚本。
- 公共网络按名称末尾的“语言或区域文字 + 编号”中括号后缀识别，其他网络默认归为私有网络。
- 请求反馈显示服务确认，版本与文档同步到 0.4.0。

## 0.3.0 · 2026-10-25

### 界面与功能

- WebUI 重做为暖白 / 深蓝侧栏 / 珊瑚色点缀的工作空间，包含总览、网络、成员、发现、活动与设置。
- 原生 GUI 同步总览、配色与矢量导航图标，启动不再附带控制台窗口。
- 两端新增网络收藏与保存、搜索筛选、跨网络成员切换、CSV / JSON 导出、活动记录、刷新间隔与紧凑列表。
- WebUI 新增成员分页、名称 / ID 排序、角色筛选、移动端布局与键盘快捷键。
- 加入 / 创建网络可以直接填写密码。破坏性请求提供确认；演示模式明确标识且禁止服务写入。

### 代码与可靠性

- Web 资源拆分为 HTML / CSS / JS；GUI 拆分页面、工作空间、主题、设置、传输和属性模块。
- 按 GUID 保持网络选择，跨网络切换清空旧成员选择，刷新后剔除已不存在的成员。
- GUI 服务失败后按刷新间隔重试；批量命令完成后只刷新一次，并报告部分发送失败。
- 服务未启动时 WebUI 仍可访问；连接失败保留旧快照并关闭写入口。
- 增加 HTTP 输入大小与并发限制、JSON 写操作校验、Origin 检查、严格 GUID / 布尔值 / 密码类型校验。
- agent 客户端增加超时、响应大小限制、UTF-8 分块正确处理、URL 校验和 `RVPNKIT_TOKEN` 支持。
- 快照不向浏览器或导出文件暴露可逆密码令牌；节点 ID 转为字符串防止精度丢失；CSV 做转义与公式注入防护。
- 统一 `dev.ps1` 构建入口，发布脚本移除个人机器路径并保护已有发布目录。
- README 聚焦当前 Rust 主线，旧版说明归档至 `docs/legacy`。

### 验证范围

新增 Rust 回归覆盖导出、配置、HTTP 解析、错误输入、URL / GUID 解码和分块 UTF-8；保留协议字节与密码令牌测试。Playwright 覆盖 Web 主要交互、只读模式、导出、移动端与错误恢复；原生截图覆盖六页和深色总览。

服务变更使用演示模式或拦截响应验证，未对真实 Radmin VPN 网络进行增删、改名或成员管理。
